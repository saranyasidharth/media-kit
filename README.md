# Instagram Media Kit - @saranya_sidharth

Professional media kit for brand collaborations and partnerships.

## 📋 Contents

- `index.html` - Complete media kit webpage with all your Instagram statistics, audience demographics, and services

## 🌐 How to Use

### Option 1: View in Browser
1. Double-click `index.html` to open it in your default web browser
2. Review the content to ensure everything looks correct
3. Share the file directly with brands or use Option 2 to create a PDF

### Option 2: Export to PDF (Recommended for Sending to Brands)

#### Method A: Using Your Browser (Chrome/Edge)
1. Open `index.html` in Google Chrome or Microsoft Edge
2. Press `Ctrl + P` (or `Cmd + P` on Mac) to open Print dialog
3. Select "Save as PDF" as the destination
4. **Important Settings:**
   - Layout: Portrait
   - Paper size: A4
   - Margins: Default
   - Background graphics: **Enabled** (important for colors)
5. Click "Save" and name it `Saranya_Sidharth_Media_Kit.pdf`

#### Method B: Using Microsoft Edge (Best Quality)
1. Right-click `index.html` → Open with → Microsoft Edge
2. Click the three dots (⋯) → Print
3. Choose "Save as PDF"
4. Enable "Background graphics"
5. Save the PDF

#### Method C: Online PDF Converter
1. Upload `index.html` to a service like:
   - https://www.web2pdfconvert.com/
   - https://pdfcrowd.com/
2. Download the generated PDF

## 🎨 Customization Tips

The media kit uses a pink/purple color scheme that matches fashion/beauty branding. To change colors:
1. Open `index.html` in a text editor
2. Find the `:root` section near the top (around line 18)
3. Modify these values:
   - `--primary-color: #E91E63;` (pink)
   - `--secondary-color: #9C27B0;` (purple)
